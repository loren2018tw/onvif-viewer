# Triage 標籤

各 skill 以五個標準 triage 角色溝通。本檔將角色對應到這個 repo issue tracker 實際使用的字串。

| 標準角色 | 本 repo 使用的字串 | 意義 |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | 維護者需要評估此 issue |
| `needs-info` | `needs-info` | 等待回報者提供更多資訊 |
| `ready-for-agent` | `ready-for-agent` | 規格完整，可交給 AFK agent |
| `ready-for-human` | `ready-for-human` | 需要人工實作 |
| `wontfix` | `wontfix` | 不會處理 |

當 skill 提到某個角色（例如「套用 AFK-ready triage 標籤」），使用表中對應的字串。
