# 搜尋結果新增「隱藏已儲存」勾選框

Status: ready-for-agent

## 需求

「搜尋結果」清單上方新增「隱藏已儲存」勾選框。勾選後，已存在於「已儲存攝影機」清單的搜尋結果不再顯示。

## 判定鍵

與後端 `src-tauri/src/storage.rs` 的 `add_camera` 去重一致：`address` 與 `port` 完全相等。同 IP 不同連接埠視為不同攝影機；不做 trim 或大小寫正規化，避免前後端判定不一致。

## 行為

- 勾選框位於「搜尋結果」標題列與清單之間，預設未勾選。
- 「搜尋結果 (N)」的 N 維持搜尋到的總數；勾選列右側顯示「已隱藏 N 台」（僅在 N > 0 時顯示）。
- 全部被隱藏時顯示「搜尋結果皆已儲存」；完全沒有搜尋結果時仍顯示「尚無搜尋結果」。
- 勾選狀態是元件內的暫時狀態，切換頁面後重置；不寫入設定。
- 勾選期間新增已儲存攝影機，對應的搜尋結果即時消失。

## 驗收條件

- [x] 未勾選：顯示全部搜尋結果
- [x] 勾選：已儲存的攝影機消失，同 IP 不同 port 仍顯示
- [x] 勾選列右側顯示「已隱藏 N 台」
- [x] 取消勾選：全部恢復顯示
- [x] 勾選期間儲存一台搜尋結果：該列即時消失、計數更新
- [x] 全部已儲存：顯示「搜尋結果皆已儲存」
- [x] 無搜尋結果：顯示「尚無搜尋結果」
- [x] `pnpm build`（vue-tsc）通過
