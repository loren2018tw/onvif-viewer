# 左側面板拆成「已儲存攝影機」與「搜尋攝影機」兩個分頁

Status: ready-for-agent

## 問題

左側面板把搜尋控制卡、搜尋結果、已儲存清單三段垂直堆疊；搜尋結果被限制在 `1fr`（窄視窗時固定 220px）的格線列裡，103 筆結果只剩約 120px 可捲動。

## 變更

- 左側面板改為單一卡片 + 分頁列：已儲存攝影機（預設）／搜尋攝影機。
- 分頁內不再重複卡片標題；「新增攝影機」按鈕移到分頁列右側，兩個分頁都可用。
- 已儲存頁：快速篩選列右側顯示 `共 N 台`，篩選中顯示 `M / N 台`。
- 搜尋頁：外層分頁內的「自動搜尋／手動掃描」改為 segmented 控制項，避免雙層 tab bar；搜尋結果列顯示總數、「已隱藏 N 台」與「隱藏已儲存」勾選框。
- 切換分頁保留搜尋結果、IP 輸入、篩選字串與勾選狀態，不重新搜尋。
- 窄視窗（< 1280px）左側面板固定為視窗高度並在分頁內捲動，預覽面板接在下方。
