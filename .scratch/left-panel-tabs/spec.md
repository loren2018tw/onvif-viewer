# 左側面板分頁化

## 目標

把左側面板的「已儲存攝影機」與「搜尋攝影機」拆成獨立分頁，讓每個清單都能吃滿面板剩餘高度。原本搜尋控制卡固定佔上方，兩個清單再以 1fr/2fr 分割，103 筆搜尋結果只剩約 120px 可捲動；窄視窗（< 1280px）時清單列更被壓成固定的 220px。

## 結構

- 左側面板只有一張卡：上方是分頁列（已儲存攝影機／搜尋攝影機）與右側的「新增攝影機」按鈕，下方是分頁內容。
- 已儲存攝影機頁：快速篩選 + 計數（`共 N 台`／篩選中為 `M / N 台`）+ 清單。
- 搜尋攝影機頁：自動搜尋／手動掃描的 segmented 控制項 + 搜尋結果列（總數、已隱藏 N 台、隱藏已儲存）+ 清單。
- 分頁狀態與清單狀態都存在元件內：切換分頁不重新搜尋、不重設篩選或勾選。

## 高度模型

- 桌面（≥ 1280px）：左側面板等於容器高度，清單在分頁內捲動。
- 窄視窗（< 1280px）：左側面板固定為視窗高度（`calc(100vh - 96px)`，最小 520px），預覽面板接在下方，需向下捲動。

## 不在範圍內

- 右側預覽面板的版面
- 搜尋、篩選、隱藏已儲存的判定規則
